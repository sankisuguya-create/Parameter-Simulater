# ケイドロ・パラメータ実験室

ケイドロの条件を変え、参加者の動きと結果の連鎖を二画面で比較するブラウザ内シミュレーターです。小学3年生が「予想→試す→結果を見る→説明を見直す」を繰り返せる操作量に絞っています。

初期フィールドは実際の運動場を基にした横70m×縦40mで、牢屋を右上寄りに置いています。比較画面は「上下」「左右」を切り替えられ、横長の範囲を大きく表示できます。

「場所」では矩形を指定し、その内側または外側を立ち入り禁止領域にできます。禁止領域は赤く表示され、すべての鬼・逃げの移動に反映されます。牢屋との位置関係が矛盾する設定は実験開始前に検出します。

## 起動

ES Modulesを使うため、ローカルHTTPサーバーで開きます。

```powershell
python -m http.server 4173
```

`http://localhost:4173/` を開いてください。外部ライブラリ、ログイン、サーバー保存はありません。

## モデルの範囲

- 固定時間刻み 0.05秒。同じ条件・初期配置なら同じ結果になります。
- 鬼は追跡・守り・餅に分かれます。逃げは危険時に逃走し、条件に応じて救出へ向かいます。
- 捕まった逃げは青色になり、徒歩の速さで牢屋へ向かいます。到着後は牢屋内を動くか境界付近で待ち、味方に直接タッチされたときだけ復帰します。
- 鬼と逃げは必要な場面で本気走りを使います。初期値では10秒で使い切り、その後20秒は回復のため歩きます。
- 走力の10段階は50m走の秒数を参考にしたアプリ独自の代表値です。公式得点ではありません。
- 疲労、加速、視野、身体接触、実在する児童の心理は再現していません。楽しさは自動採点しません。

## ファイル

- `index.html`: 画面
- `styles.css`: レスポンシブ表示
- `simulator.js`: 状態遷移と固定刻み計算
- `app.js`: 操作、Canvas描画、比較表示
- `tests/simulator.test.mjs`: 主要なルールの検証

## 配布

静的ファイルなのでGitHub PagesまたはGASのHTML配信に載せられます。Classroom APIは使いません。児童の氏名や実測値はリポジトリへ保存しないでください。
