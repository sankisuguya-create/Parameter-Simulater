# ケイドロ・パラメータ実験室

ケイドロの条件を変え、参加者の動きと結果の連鎖を二画面で比較するブラウザ内シミュレーターです。小学3年生が「予想→試す→結果を見る→説明を見直す」を繰り返せる操作量に絞っています。

初期フィールドは実際の運動場を基にした横70m×縦40mで、牢屋を右上寄りに置いています。比較画面は「上下」「左右」を切り替えられ、横長の範囲を大きく表示できます。

運動場中央の矩形（左23m・上11m・幅24m・高さ18m）は、初期状態で立ち入り禁止です。「場所」では矩形を変更し、その内側または外側を禁止領域にできます。禁止領域は赤く表示され、すべての鬼・逃げの移動に反映されます。牢屋との位置関係が矛盾する設定は実験開始前に検出します。

追う鬼は赤い星、守りは暖色の縦長長方形、餅は暖色の不定形な楕円です。逃げは青い円で、捕獲後と牢屋内では灰色になります。鬼は追跡対象を分担し、近づきすぎると離れる方向へ動きます。

追う鬼は一度決めた逃げを継続して追います。標的を捕まえた、標的に設定距離以上離された、または別の逃げが至近距離に入った場合だけ標的を切り替えます。鬼と逃げはそれぞれ、人数の何%を別の走力にするかを指定できます。同じ条件と初期配置なら、別走力になる番号も同じです。

逃げは「標準」「逃げに徹する」「牢屋から離れる」「鬼から離れる」「助ける」の5タイプです。後4タイプを10%刻みで配分し、残りを標準にします。合計が100%を超える条件は開始前に拒否します。タイプの割当ても固定シードに従うため、A/Bで条件を揃えれば同じ番号へ割り当てられます。

AとBには独立した条件メニューがあり、Aは左、Bは右から開きます。相手側の条件をコピーしてから一項目だけ変えることもできます。捕獲時には短い鍵の金属音、救出時には鈴音をWeb Audioで生成します。

条件メニューには、基準1:3、逃げ有利1:5、鬼有利1:2、伝統的基準1:1、守り比較1:3のパターンがあります。各パターンには鬼・逃げの走力分布を含め、餅は0人に固定しています。自治体資料では同数が基本とされていますが、教育実践では走力や役割を含めて児童が人数を話し合うことが重視されています。このアプリの1:3は、救出あり・70m×40mで試行錯誤を始めるための仮説であり、普遍的な最適値ではありません。

人数比の参考：[中野区「子どもと一緒に遊ぼう」](https://kugikai-nakano.jp/shiryou/1431418622.pdf)／[教育出版「鬼が何人ならちょうどいい？」](https://www.kyoiku-shuppan.co.jp/docs/e-na/es5/pageindices/index13.html)

## 起動

ES Modulesを使うため、ローカルHTTPサーバーで開きます。

```powershell
python -m http.server 4173
```

`http://localhost:4173/` を開いてください。外部ライブラリ、ログイン、サーバー保存はありません。

## モデルの範囲

- 固定時間刻み 0.05秒。同じ条件・初期配置なら同じ結果になります。
- 鬼は追跡・守り・餅に分かれます。逃げは危険時に逃走し、条件に応じて救出へ向かいます。
- 捕まった逃げは青色になり、徒歩の速さで牢屋へ向かいます。到着後は牢屋内を動くか境界付近で待ち、味方に直接タッチされたときだけ復帰します。
- 鬼と逃げは必要な場面で本気走りを使います。初期値では10秒で使い切り、その後20秒は回復のため歩きます。
- 走力の10段階は50m走の秒数を参考にしたアプリ独自の代表値です。公式得点ではありません。
- 疲労、加速、視野、身体接触、実在する児童の心理は再現していません。楽しさは自動採点しません。

## ファイル

- `index.html`: 画面
- `styles.css`: レスポンシブ表示
- `simulator.js`: 状態遷移と固定刻み計算
- `app.js`: 操作、Canvas描画、比較表示
- `tests/simulator.test.mjs`: 主要なルールの検証

## 配布

静的ファイルなのでGitHub PagesまたはGASのHTML配信に載せられます。Classroom APIは使いません。児童の氏名や実測値はリポジトリへ保存しないでください。

### Google Apps Script版

`gas/`には、学校端末からGASの公開URLだけで利用できる配布版があります。

- `gas/Code.gs`: Webアプリの入口
- `gas/Index.html`: CSS・シミュレーション・画面操作を一つにまとめたHTML
- `gas/appsscript.json`: V8ランタイムと日本時間の設定

GASのエディタで新しいプロジェクトを作り、`Code.gs`を置き換え、HTMLファイルを`Index`という名前で追加して`gas/Index.html`の内容を貼り付けます。その後、「デプロイ」→「新しいデプロイ」→「ウェブアプリ」で公開します。生徒用アカウントで公開URLを開けることを確認してから配布してください。

校務PCでの詳しい作業は[`GAS-SETUP.md`](GAS-SETUP.md)を参照してください。

元の画面やロジックを変更したときは、次のコマンドで`gas/Index.html`を再生成します。

```powershell
npm run build:gas
```

生成後はGASの`Index`を置き換え、「デプロイを管理」から新しいバージョンを反映します。`gas/Index.html`は自動生成物なので、直接編集しません。
