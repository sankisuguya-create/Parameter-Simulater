# 大なわ 八の字とびの しくみ ─ GASウェブアプリとして公開する手順

このディレクトリで**GASプロジェクト1つ**（ケイドロ版とは別プロジェクト）。3年 国語「話し合い」単元で使う。

`shikumi.html` は単一ファイルで完結する（外部読み込み・ビルドなし）。手元ではブラウザで直接開けば、全部の変数が出た状態で動く。

| ファイル | 中身 |
|---|---|
| `shikumi.html` | シミュレータ本体（上から見た図・横から見た図・3分間の回数） |
| `Code.gs` | 児童画面と先生画面（`?p=sensei`）の出し分け、児童に出す変数の保存 |
| `appsscript.json` | V8・日本時間（ケイドロ版と同じ） |
| `pictogram/` | 横から見た図のピクトグラム元SVG（6枚。`shikumi.html` に埋め込み済み） |

- 児童画面：先生が「児童に 出す」にした変数だけが出る。出していない変数は初期値のまま動く
- 先生画面（`?p=sensei`）：全部の変数と、変数ごとの「児童に 出す／出さない」ボタン。押すとすぐ保存される
- 児童画面への反映は、児童がページを**開き直したとき**

## 1. プロジェクトを作る

1. https://script.google.com →「新しいプロジェクト」→ 名前を「八の字とびの しくみ」に

## 2. ファイルを2つ用意する

| GAS上のファイル名 | 貼りつける内容 |
|---|---|
| `コード.gs`（既定のもの） | `Code.gs` の中身 |
| `shikumi`（HTML） | `shikumi.html` の中身 |

## 3. デプロイ

1. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
2. 次のユーザーとして実行：**自分**
3. アクセスできるユーザー：**児童のアカウントが開ける範囲**（下の「確認が必要な点」）
4. 表示された `.../exec` のURLを控える

## 4. 使う

- 児童：`（URL）` をClassroomに貼る
- 先生：`（URL）?p=sensei` を自分で開く（児童には配らない）

授業の流れ：はじめは「回す はやさ」だけが出ている。児童から変数が出たら、先生画面でその変数の「出さない」を押して「児童に 出す」に変え、児童に開き直してもらう。

## 5. 更新するとき

「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」。URLは変わらない。

## 確認が必要な点

- **先生の判定**：`Session.getActiveUser().getEmail()` で `@edu.nishi.or.jp` かどうかを見る。「自分として実行」のウェブアプリでは、**デプロイした人と同じドメインの人のメールしか取れない**。先生は同じドメインなので取れ、児童（`@kyoiku.edu.nishi.or.jp`）は取れないか児童のアドレスになるので、どちらでも児童画面になる。**最初に先生画面が開けるかを自分で確かめる**こと。開けない場合は先生判定のやり方を変える必要がある。
- **アクセス範囲**：児童のドメインが先生と別ドメインの場合、「同じドメイン内の全員」では児童が開けないことがある。児童アカウントで開けるか、実機で確認する。
- **保存の範囲**：「児童に 出す」はプロジェクトに1つだけ保存される。複数学級で同じURLを使うと、出す変数も共通になる。学級ごとに分けるならプロジェクトを学級ごとに作る。
